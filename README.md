### the legend (read this first)

Sci-fi taught me worlds can be *designed*. Art taught me they should be *felt*. Code is where those two arguments finally stop fighting.

I sketch the strange version first — the cut that would never survive a spec review. Then I go back and weld the joints: types, tests, boring reliability. **Weird is the draft. Reliable is the print run.**

I am not collecting frameworks. I am mapping terrain: pixels to APIs to models that hallucinate with confidence. Someone has to draw the roads.

<p>
